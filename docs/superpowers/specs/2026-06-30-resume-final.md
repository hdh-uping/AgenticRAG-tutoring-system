## AgenticRAG 驱动的双 Agent 智慧教学系统

**技术栈**：Python、LangGraph、FastAPI、Milvus、Neo4j、MinerU、SQLite、Qwen3 系列

**项目背景**：面向个性化教学场景，针对传统辅导知识检索碎片化、多跳推理弱等问题，设计以 AgenticRAG 为核心的双智能体协作系统，覆盖精准答疑、薄弱点诊断与学习引导全流程。

**技术实现**：

- **LangGraph 协作链路与插件化架构**：设计 Tool → Skill → Agent 能力分层，将混合检索、诊断等复杂逻辑封装为可复用 Skill。以此构建教学与评估双 Agent 图工作流：教学 Agent 动态规划检索，评估 Agent 溯源诊断，两者协同实现教评闭环。

- **多模态解析与双源知识库构建**：针对复杂版面课件（双栏、表图混排），利用 MinerU 结合 VLM 提取图表语义。通过 LLM 自动抽取实体与依赖关系，双写至 Milvus 与 Neo4j，实现向量与图谱的双源支撑，整体检索召回率达 85.2%。

- **AgenticRAG 多跳引擎与幻觉阻断**：设计「宽召回，精排序」两阶段检索策略——首轮 BM25 与向量双路并行召回，基于 RRF 融合多路召回结果完成粗排，再结合 Qwen3-Reranker 进行语义级重排，过滤噪音并提升查准率。当证据不足时 Agent 自主沿知识图谱依赖链逐跳补全前置知识。设计证据自评与三级降级机制客观校正置信度以阻断幻觉扩散，端到端准确率达 83.6%，多跳类问题准确率提升 18.3%。

- **分层记忆体系与个性化画像追踪**：构建多级状态管理，推理中间状态驻留内存，多轮对话历史持久化至 SQLite。将学生认知画像存入 Neo4j 进行跨会话追踪，并结合画像掌握度动态控制 RAG 检索深度，支撑长效个性化教学。


## 指标说明（面试备忘）

| 指标 | 数值 | 面试怎么讲 |
|---|---|---|
| 端到端准确率 | **83.6%** | 50 条测试集分三类（单跳/多跳/迭代），LLM-as-judge 对照参考答案评分 |
| 召回率 | **85.2%** | BM25+向量混合 + RRF + Reranker 后 Recall@5。基线（仅向量）约 72% |
| 多跳提升 | **+18.3%** | vs 朴素 RAG 基线，多跳类问题（需前置知识补全）提升显著 |
