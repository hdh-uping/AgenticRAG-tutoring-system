## 版本 A：详细版（适合项目经历作为简历主体，6 条亮点）

**项目名称**：AgenticRAG 驱动的多 Agent 智慧教学辅导系统

**项目角色**：个人项目 / 独立设计开发

**技术栈**：Qwen2.5-14B、Qwen3-Embedding、Qwen3-Reranker、Qwen-VL、LangGraph、Neo4j、Milvus、MinerU、FastAPI、Docker

**项目背景**：
针对传统教学辅导知识检索碎片化、缺乏个性化引导、多 Agent 协同记忆断层等痛点，设计并实现一个以 AgenticRAG 为核心的智慧教学知识引擎，覆盖答疑讲解、学习诊断、启发式引导全流程。

**核心技术工作**：

- **基于 LangGraph 设计 Supervisor 多 Agent 调度架构**：调度 Agent（Orchestrator）根据学生意图与认知画像编排答疑/诊断/引导子 Agent，通过共享学生画像实现跨 Agent 协同；全局仅两层 LLM 决策（外层调度派单 + 内层 RAG 检索），兼顾灵活性与可控性。

- **设计 AgenticRAG 自主检索引擎（项目核心）**：主 RAG Agent 内部采用 ReAct 框架，基于"证据缺口类型"（缺前置知识 / 检索词不准 / 知识库外）动态规划检索路径，自主决定调用混合检索、知识图谱查询或查询改写，最多 6 轮迭代，突破传统 RAG 固定流水线的局限。

- **知识图谱多跳检索（差异化亮点）**：首轮 BM25 + 向量混合检索经 RRF 融合、Qwen3-Reranker 重排后，当证据不足且判定为前置知识缺失时，沿 Neo4j 知识图谱 PREREQUISITE 依赖边做多跳补全，结合学生画像掌握度触发，解决朴素 RAG 无法补全"理解所需前置知识"的痛点。

- **证据充分性自评与降级机制**：每轮检索后由 LLM 自评证据充分性，结合各 chunk 重排分数作为客观兜底防止过度自信；6 轮仍未充分时按置信度分流（尽力作答+标注不确定性 / 坦诚拒答 / 转人工），规避幻觉风险。

- **MinerU 离线知识库构建流水线**：版面分析分类处理图文表公式，VLM 描述课件图片使其可被向量检索；LLM 抽取知识点与前置依赖，同一结果同时写入 Milvus（chunk 向量 + source_kp 字段）与 Neo4j（知识点图谱），支撑在线多跳检索。

- **标准化 Agent Skill 与分层记忆**：设计 5 类可复用 Skill（薄弱点诊断/启发式引导/概念讲解/认知更新/合规守门），每个封装独立 I/O 与校验规则；短期记忆（LangGraph State）承载单轮推理状态，长期记忆（Neo4j 画像）跨会话追踪认知，支撑画像驱动的个性化讲解。

**项目成果**：
- 设计并实现完整 Prompt 工程（覆盖调度、ReAct 检索、证据评估、诊断引导等 12 类核心 prompt）。
- 构建 20~50 条三类评测集（单跳 / 多跳 / 迭代），对比朴素 RAG，多跳检索策略在多跳类问题上准确率提升 `[需实测填入]`。

## 版本 B：精简版（适合简历空间紧张，4 条亮点）

**项目名称**：AgenticRAG 驱动的多 Agent 智慧教学辅导系统（个人项目）

**技术栈**：Qwen2.5-14B / Qwen3-Embedding+Reranker / LangGraph / Neo4j / Milvus / MinerU

- 设计 LangGraph Supervisor 多 Agent 调度架构，调度 Agent 编排答疑/诊断/引导子 Agent；主 RAG Agent 内部用 ReAct 基于"证据缺口类型"动态规划检索路径，突破朴素 RAG 固定流水线局限。
