# ## 算法 2.16 双向循环链表的插入(1)

## 算法 2.16 双向循环链表的插入(1)

```c
void inselem(DuLinkList L, ElemType e, DuLNode *p)
/*设 L 为双向循环链表的头节点，在地址为 p 的节点之后插入地址为 s 的新节点*/
{ DuLNode *s, *r;
    s = (DuLNode*)malloc(sizeof(DuLNode));
    s->data = e;    /*建立一个新节点 s*/
    r = p->next;
    s->next = r;
    r->prior = s;    /*插入在节点 p 之后*/
    p->next = s;
    s->prior = p;
}
```
