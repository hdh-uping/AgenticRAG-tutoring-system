## 算法 2.8 带头节点的单链表初始化

单链表的初始化就是构建一个空的单链表，若成功，则返回其头指针，否则返回-1。

```c
LinkList Init_LinkList(LinkList L)
/*构建一个带头节点的空链表，用 L 返回其头指针，若失败则返回 -1*/
{    L=(LNode *)malloc(sizeof(LNode));    /*分配一个头节点*/
    if(!L) return -1;    /*分配失败*/
    L->next = NULL;    /*头节点的指针域为空*/
    return L;
}
```
