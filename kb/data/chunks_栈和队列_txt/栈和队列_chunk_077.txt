(6) 取队头。

```c
int QueueFront(SqQueue Q, Elemtype &e)
{
    if(QueueEmpty(Q)) return ERROR; // 队空
    e = Q.data[(Q.front + 1) % MAXSIZE]; // 取出队头数据
    return OK;
}
```

(7) 求队列长度。

```txt
int QueueLength(SqQueue Q)
{
    return (Q.rear-Q.front+MAXSIZE)%MAXSIZE;
}
```
