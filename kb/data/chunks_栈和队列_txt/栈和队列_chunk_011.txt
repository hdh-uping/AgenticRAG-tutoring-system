## 2. 顺序栈的算法实现

（1）初始化栈（置栈空）。

初始化栈主要是分配存储空间，并将栈顶指针置为-1。

```txt
int InitStack(SqStack &S)
//构造一个空栈
{
    S.top=-1;
    return OK;
}
```

(2) 判栈空。

```txt
int StackEmpty(SqStack S)
//判栈为空栈时返回值为真,反之为假
{ return(S.top==-1? TRUE:FALSE); }
```

(3) 判栈满。

```c
int StackFull(SqStack S)
//判栈为满栈时返回值为真,反之为假
{ return(S.top==MAXSIZE-1?TRUE:FALSE); }
```
