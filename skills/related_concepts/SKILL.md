# related_concepts

## 作用
根据学生当前提问涉及的概念，沿知识图谱的关系边找到关联知识点，推荐"你可能还想了解"的下一步学习内容。

## 触发条件
- 教学 Agent 完成答疑后，由独立推荐 Agent 调用

## 不适用
- 不是"诊断薄弱点"——不查画像、不评分
- 如果图谱中没有关联节点，返回空

## 内部流程
```
本轮概念 → 推荐 Agent 调用 Skill → Neo4j/本地 JSON 沿 IS_A / HAS_OPERATION 查候选 → 推荐 Agent 结合本轮语境筛选
```

### 各步骤说明
1. **图查询关联**：对每个概念，查：
   - 同级操作：同一数据结构的其他 HAS_OPERATION（如学生问了 push，推荐 pop）
   - 兄弟结构：同一 IS_A 父类型下的其他子类型（如问了顺序表，推荐单链表）
   - 父类型：IS_A 向上追溯（如问了顺序栈，推荐栈的概念）
2. **均衡与去重**：排除本轮已经涉及的概念；多概念问题按概念轮询候选，避免第一项占满名额
3. **Agent 筛选**：独立推荐 Agent 结合原问题和教学回答，从候选中选择 0~2 个并解释承接关系；不得生成候选外的概念

### 输出格式
Skill 返回候选名称；推荐 Agent 最终呈现为带理由的独立区块，例如：

```markdown
## 推荐继续学习

- **队列·出队**：与栈的弹出操作对照，可以继续观察 FIFO 与 LIFO 在删除端的差别。
```

没有关联概念时返回空。

## 依赖
- Neo4j 知识图谱；不可用时自动使用仓库内 JSON 图谱
- 当前配置的 LLM：用于推荐 Agent 的候选筛选；失败时退回确定性候选模板
